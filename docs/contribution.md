改了什么、怎么验证**。

## 五、三个"AI 写错、我改对"的案例

### 案例 1：配置漏传导致两条检索路径不一致

- 现象：`/api/rag/search` 与 Agent 检索返回的分块不同；
- 定位：核对"注释与代码是否一致"时发现服务构造漏传 `chunk_strategy`；
- 修复：补传参数；
- 验证：两条路径策略一致，回归指标不变。

### 案例 2：拒答白名单让指标失真

- 现象：三项指标恒为 1.000，换 embedding 纹丝不动；
- 定位：指标"不该不变"；样本全是负样本 + 硬编码白名单；
- 修复：余弦阈值 + 平衡集；
- 验证：拒答 0.562 → 0.896。

### 案例 3：阈值随语料漂移

- 现象：知识库扩容后拒答从 0.958 跌到 0.771；
- 定位：可行区间从 (0.409, 0.537) 漂到 (0.489, 0.567)，旧阈值掉出区间；
- 修复：重新标定到 0.53，并写入"语料变更必须重标定"的约束；
- 验证：拒答回升至 0.896。
